# Ручное обогащение TurnBench

Как собираем реальные данные для обогащения аудиодатасета
[TurnBench — Dev Set](https://huggingface.co/datasets/mundo-ai/turn-benchmark-dev).
Задача — поиск концов реплик (end of turn, EOT) в потоке речи.
Обогащение текстового датасета — в [enrichment.md](enrichment.md).

## Постановка задачи

Модель слушает разговор и должна отметить на временной оси моменты, когда спикер закончил реплику
и отдал слово. Это детекция событий во времени, а не классификация готовых объектов: на входе непрерывная
дорожка, на выходе — список моментов «конец реплики».

- Экземпляр — конец реплики: момент времени на дорожке спикера.
- Эталон в TurnBench — концы отрезков-реплик (Normal Turn, Strong Floor Hold, Bounded Response).
- Метрики: точность, полнота и F1 найденных концов реплик с допуском по времени, задержка срабатывания
  относительно настоящего конца реплики, доля ложных срабатываний внутри реплики (модель «перебивает» спикера).

Как получаем такую разметку для собранных разговоров: конец реплики всегда совпадает с концом какого-то
отрезка речи спикера, и после него в дорожке спикера почти всегда есть пауза — он молчит, пока говорит
собеседник. Поэтому достаточно найти в дорожке все паузы и для каждой решить, закончилась ли перед ней
реплика (`eot`) или спикер просто замолчал внутри неё (`hold`). Паузы с меткой `eot` дают все концы реплик
с точным временем, то есть разбиение дорожки на реплики в том же виде, что у отрезков-реплик TurnBench.
Последний конец речи в дорожке не учитываем ни у нас, ни в TurnBench: там заканчивается запись, а не реплика.

## Требования курсовой

- Датасет изображений, аудио, видео или 3D — не менее 3000 экземпляров, задача не только классификация.
- Вручную собрать 50–100 новых экземпляров на каждый класс или пропорционально объёму классов.
- Для каждого источника указать URL, дату обращения и лицензию.
- Каждый собранный экземпляр размечают не менее двух аннотаторов по codebook, с фиксацией времени разметки.

## Как устроен TurnBench

Проверено по карточке датасета, лицензии и аннотациям 17.11.2026.

- 38 разговоров двух людей на английском, около 7,3 часа.
- У каждого спикера своя дорожка (FLAC, 48 кГц, моно) и три независимых трека разметки от трёх аннотаторов.
- Разметка — отрезки с меткой и расшифровкой. Для EOT нужны отрезки-реплики (Normal Turn, Strong Floor Hold,
  Bounded Response): их конец — кандидат в конец реплики. Остальные метки (поддакивания, перебивания, шум и т. п.)
  не используем.
- Лицензия Dataset Public License v1.0: указание авторства, только некоммерческое использование,
  запрет клонирования голоса.

## Решения

| Решение | Почему |
|---|---|
| Задача — только концы реплик, без поддакиваний и перебиваний | Решение команды; для остальных событий TurnBench пришлось бы размечать отрезки вручную |
| Задача модели — детекция концов реплик во времени | TurnBench — разметка событий на временной оси, а не набор готовых объектов с метками |
| Разметка собранного — отрезками реплик на временной оси поверх готовых отрезков речи: по каждой паузе от 200 мс аннотатор решает, склеить отрезки в одну реплику или оставить границу | Отрезки речи и паузы уже есть в источнике, аннотатор только склеивает: разметка быстрая. Согласие считается каппой Коэна по паузам и F1 по концам реплик |
| Объём — все паузы собранных разговоров | Иначе часть концов реплик потеряется |
| Собираем разговоры двух людей с отдельной дорожкой на каждого | Формат совпадает с TurnBench |
| Сами разговоры не записываем | Решение команды |
| Источник — Seamless Interaction (Meta), часть `naturalistic`, только разговоры на заданную тему | См. «Выбор источника» |
| Аудио не храним в git, в репозитории — только опись | Около 400 МБ; файлы восстанавливаются по описи из открытого источника |

Почему Seamless Interaction:

- у каждого участника своя дорожка с той же частотой дискретизации, что в TurnBench;
- в части `naturalistic` обычные люди разговаривают на заданную тему — как в TurnBench;
- лицензия разрешает адаптацию для некоммерческих целей.

## Что собрано

10 разговоров из `naturalistic/dev`, 20 дорожек, 18,2 минуты разговоров (36,4 минуты дорожек).

- Все разговоры — тип `ipc_conversation` (разговор на заданную тему); игры и совместное сочинение историй исключены.
- Пять пар знакомы между собой (друзья, родственники и другие знакомые), пять — незнакомы.
- Три поставщика записей (V00, V01, V03), все сессии и темы разные.
- Длительность каждого разговора — от 76 до 148 секунд.
- Речь английская.

Пауз от 200 мс между отрезками речи — 543; это кандидаты в концы реплик, по ним и размечаем.

## Разметка

- [`scripts/make_turn_tasks.py`](../scripts/make_turn_tasks.py) готовит задачи: одна задача — один разговор,
  две синхронные дорожки 16 кГц (`data/manual_audio/turns_audio/`, не в git). На дорожки заранее ставятся
  отрезки речи, в данные задачи записывается список пауз от 200 мс
  (`data/manual_audio/tasks_turns.json`).
- [`scripts/setup_labelstudio_turns.py`](../scripts/setup_labelstudio_turns.py) создаёт в Label Studio проект
  «TurnBench: реплики»: у каждого спикера своя дорожка и метка «Реплика спикера N». Аннотатор склеивает
  отрезки речи в реплики; конец каждого отрезка-реплики — конец реплики.
  Каждый разговор размечают два аннотатора.
- Правила разметки — [codebook_eot.md](codebook_eot.md).
- После разметки проект выгружается в JSON (`data/annotations/`). Согласие считает
  [`scripts/annotation_agreement.py`](../scripts/annotation_agreement.py): по каждой паузе — оказалась она
  внутри реплики или на границе (процент согласия и каппа Коэна), и по концам реплик — сколько концов
  совпало у двух аннотаторов с допуском 0,5 с (F1).

Итоги разметки 18.11.2026 (аннотаторы: 1 — Егор, 4 — Антон; выгрузка
[`data/annotations/turns_labelstudio.json`](../data/annotations/turns_labelstudio.json)):

| Показатель | Значение |
|---|---|
| Разговоров, размеченных обоими | 10 из 10 |
| Пауз | 543 |
| Процент согласия по паузам | 94,8 % |
| Каппа Коэна по паузам | 0,79 |
| Паузы Егора / Антона (конец реплики : внутри реплики) | 84 : 459 / 70 : 473 |
| Концы реплик Егора / Антона | 104 / 90 |
| Совпало концов реплик (допуск 0,5 с), F1 | 83, 0,86 |

Расхождений 28, больше половины — в разговорах `a05` и `a07`, где собеседники часто перебивают друг друга
короткими репликами. Спорили в основном о трёх ситуациях: короткая реакция слушающего («yeah», «okay»)
посреди чужой речи (случай 6), законченная фраза, после которой собеседник молчит, а спикер начинает новое
(случай 2), и оборванная фраза, которую спикер продолжает после вставки собеседника (случай 3).
Итоговые метки пауз — в [`data/annotations/turns_labelstudio_labels.csv`](../data/annotations/turns_labelstudio_labels.csv),
колонка `final_label`: 85 концов реплик, 458 пауз внутри реплик.

## Файлы

### `data/manual_audio/sources.csv`

Те же колонки, что у текстового датасета: `source_id`, `name`, `url`, `license`, `accessed_at`.

### `data/manual_audio/conversations.csv`

| Колонка | Что |
|---|---|
| `conversation_id` | наш номер разговора, `a01` … `a10` |
| `source_id` | ключ из `sources.csv` |
| `source_ref` | часть, раздел и ключ разговора в источнике |
| `speaker_1_file`, `speaker_2_file` | идентификаторы дорожек в источнике; имена файлов в `raw/` |
| `relationship` | знакомы ли участники: `familiar` или `stranger` |
| `duration_s` | длительность разговора в секундах |
| `collected_by`, `collected_at` | кто и когда собрал |

### `data/manual_audio/tasks_turns.json`

Задачи для Label Studio: ссылки на дорожки, `conversation_id`, `duration_s`, список пауз `pauses`
(`pause_id`, `speaker`, `start`, `end`) и предразметка — отрезки речи каждого спикера.

### `data/manual_audio/raw/` (не в git)

На каждую дорожку три файла:

- `<id>.wav` — аудио, 48 кГц, моно, 32-битные отсчёты с плавающей точкой;
- `<id>.vad.jsonl` — отрезки речевой активности;
- `<id>.transcript.jsonl` — расшифровка со временем фраз и слов.

Восстановить: для каждой дорожки из описи скачать
`https://dl.fbaipublicfiles.com/seamless_interaction/naturalistic/dev/audio/<id>.wav`,
`.../metadata/vad/<id>.jsonl` и `.../metadata/transcript/<id>.jsonl`.

## Как прошёл сбор

Сбор выполнен 17.11.2026.

1. По описи файлов источника (`assets/filelist.csv` в репозитории
   [seamless_interaction](https://github.com/facebookresearch/seamless_interaction)) найдены 748 пар дорожек
   в `naturalistic/dev`, из них 570 — разговоры на заданную тему.
2. Пары перемешаны с фиксированным зерном (42) и отобраны по правилам: разные поставщики, сессии и темы;
   поровну знакомых и незнакомых; длительность 1–2,5 минуты; тема — не игра со списками.
3. Скачаны только аудио, разметка речевой активности и расшифровки, без видео и признаков движения.
4. Проверены формат, одинаковая длина дорожек в паре и язык.

## Ограничения

- Формат отличается от TurnBench: WAV с 32-битными отсчётами с плавающей точкой вместо 24-битного FLAC.
  Частота и число каналов совпадают.
- Разговоры короче, чем в TurnBench (1,5–2,5 минуты против 7–15), и идут по заданной теме.
- Если пауза после конца реплики короче 200 мс, этот конец в разметку не попадёт.
- В разговорах участвуют реальные люди: использование только некоммерческое, с указанием источника.

## Отложено

- Приведение TurnBench к той же постановке: концы отрезков-реплик как события; проверить, что концов реплик
  не меньше 3000.
- Аугментации и синтез с учётом запрета клонирования голоса в лицензии TurnBench.
